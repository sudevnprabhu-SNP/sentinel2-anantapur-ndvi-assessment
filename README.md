# Sentinel-2 Anantapur NDVI — Notebook Guide

## Phase sequence
1. `01_Getting_Started_Sentinel2.ipynb` — original supplied notebook: product structure, bands, true colour, introductory NDVI.
2. `02_NDVI_Introduction_and_Inspection.ipynb` — original supplied notebook: inspect an NDVI GeoTIFF, statistics, histogram, exploratory bins.
3. `03_Cloud_Shadow_Masking.ipynb` — SCL cloud/shadow mask concepts and application.
4. `04_Study_Area_and_Clipping.ipynb` — boundary inspection and clipping to three mandals.
5. `05_NDVI_Statistics_and_Classes.ipynb` — statistics, NDVI intervals, area summaries and plots.
6. `06_Maps_Results_and_GitHub_Checklist.ipynb` — inspect result files and prepare publication.

The first two notebooks are copies of the supplied notebooks. Additional notebooks are phase-by-phase documentation/templates based on the known project workflow. They are not a literal transcript of every terminal command or historical error: the uploaded notebooks had no executed error outputs, so unverified errors are not invented. Update the editable paths and verify the original scripts before running write operations.

Run notebooks from the project root. Large rasters are intentionally not bundled.
